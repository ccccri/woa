    How to find the MAC address

    • Windows: open Command Prompt and run getmac /v. Use the "Physical Address" of the Ethernet adapter.
    • Linux: run ip link and use the link/ether value of the wired interface (for example enp9s0).
    • macOS: System Settings > Network > Ethernet > Details > Hardware.

    Wake on LAN works best over a cable. Enable it in the BIOS/UEFI and in the network card settings.

    • Windows: apri il Prompt dei comandi ed esegui getmac /v. Usa l'"Indirizzo fisico" della scheda Ethernet.
    • Linux: esegui ip link e usa il valore link/ether dell'interfaccia cablata (per esempio enp9s0).
    • macOS: Impostazioni di Sistema > Rete > Ethernet > Dettagli > Hardware.

    Il Wake on LAN funziona meglio via cavo. Attivalo nel BIOS/UEFI e nelle impostazioni della scheda di rete.
